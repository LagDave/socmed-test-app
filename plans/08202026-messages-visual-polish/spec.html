Risk
Level 2 · visibility and shared UI

Why

In a themed dark conversation, the typing label could be rendered on a mismatched card strip and become hard to read. The inbox and open-thread cards also retained a shared hover/elevation effect that was visually distracting. The user requested a concise typing label and explicitly accepted the revised local behavior.

What

Keep the existing realtime typing behavior, but display only the peer’s first name in the typing copy. Give the typing row the active conversation background so the existing theme-aware text color has a matching surface. Remove all shadows from the Messages thread and inbox cards, including their hover state. Include the existing client socket cleanup change so the shared connection is not disconnected during same-user lifecycle cleanup.

Out of scope: Socket event protocol, typing timing, chat-theme data, message behavior, backend code, and general feed-card styling.
