Why

Plan 26 shipped one-click Facebook-style reshare with no commentary. PR #56 expands the UX to match Facebook’s “Say something about this post” flow: a modal caption composer before posting, optional wrapper body on the share API, polished attribution chrome, and a success notice on post detail. The original plan explicitly deferred commentary; this plan documents and accepts that expanded scope.

What

  • SharePostDialog — modal with optional caption textarea, original-post preview, Cancel / Share post actions.
  • Feed + Post detail open the dialog from Share2 instead of silent one-click share.
  • POST /api/posts/:id/share accepts optional { body?: string }; trimmed caption stored on wrapper post.
  • ShareAttribution — “You shared Alex’s post” line with profile links on shared cards.
  • ShareSuccessNotice — polite status banner after share on post detail.
  • Empty caption allowed — wrapper body may be empty string; nested embed carries original content.
Share flow (friend’s original post):
[ Share2 click ] → SharePostDialog
  ┌─ modal ──────────────────────────────────────────┐
  │  (you)  Write a caption…                         │
  │  ┌─ Original post preview ─────────────────────┐ │
  │  │  (Alex)  Alex’s post body / image            │ │
  │  └──────────────────────────────────────────────┘ │
  │  [ Cancel ]  [ Share post ]                       │
  └──────────────────────────────────────────────────┘

Feed card after share with caption:
┌─ feed-card ─────────────────────────────────────────┐
│  You shared Alex’s post                   · 2m      │
│  Your caption text here…                            │
│  ┌─ nested original ──────────────────────────────┐ │
│  │  (Alex)  original body / image                   │ │

Constraints

Must

  • Share2 still icon-only on action row; opens dialog instead of immediate share
  • Caption optional; trim whitespace before persist
  • body optional on share API; max 5000 chars (Zod)
  • Preserve plan 26 rules: mutual friends only, no own-post share, no share-of-share
  • Shared cards show attribution + optional caption + nested original
  • Dialog dismiss via Cancel, backdrop, Escape (when not busy)

Must Not

  • Do not bypass friendship / visibility checks in the dialog layer
  • Do not require non-empty caption
  • Do not add new npm dependencies
  • Do not change normal compose body.min(1) validation

Out Of Scope

  • Share counts / notifications
  • Quote-share editing of nested original
  • OS Web Share API

Risk

Level 2 — Concern. Caption path must not weaken share authorization; empty-body wrapper must not break feed rendering.
