Why

Plans 25–26 modernized the feed composer and post cards, but the home feed still reads utilitarian next to the profile page and the in-flight navbar upgrade. The composer textarea looks like a bare form control, post photos sit inset beside the avatar column, and action rows are icon-only — fine for density, weak for scanability and “social product” feel.

This is a visual polish pass on the home feed (/) and post detail (/posts/:id). Profile timeline stays unchanged. No new features, no API changes.
