Restore the Unsent Message Border

Created 2026-08-26 for branch kylie/unsent-border. Merge target: dev.

Why

Unsent-message placeholders should retain the rounded dashed outline shown in the supplied reference image, so they remain visually distinct from ordinary chat bubbles.

What

Use the same charcoal border color as dark mode for unsent-message placeholders, via a dedicated application token that chat themes do not override. Preserve the existing rounded, dashed, transparent message treatment—without changing unsend behavior, text, grouping, actions, or chat-theme rules.

Runtime finding: the themed light-mode UI still renders the inherited token as white, even when the prior foreground-mix correction is compiled. The outline therefore needs a dedicated, theme-independent value matching dark mode’s #3a3b3c border.

Level 2 — visual regression / environment mismatch. The source already expresses the requested border. Editing it without reproducing the absence risks an unrelated CSS churn commit and still would not fix a stale deployment or an unrebuilt frontend. Recommended mitigation: validate the exact branch and running build first; apply a one-file class correction only if the declaration is missing or overridden in that target.
