Why

The stacked reaction icons at the right side of post and comment action rows do not have the compact circular spacing shown in the supplied reference. The current component has the same wrapper structure but omits the reference’s 4px icon-container padding and the emoji alignment adjustments.

What

Adjust only the non-message reaction-summary icon stack in ReactionBar so each circular icon container uses 4px horizontal and vertical padding and a 10px emoji centered in a fixed 10px inline-grid. Do not use visual margin offsets. Preserve the existing -space-x-1 overlap, background/ring, reaction count, dialog trigger, and all reaction behavior.

Done when: A single and a multi-type post/comment summary visibly match the supplied compact circular treatment; the summary remains clickable and opens its people list; picker and count behavior remain unchanged; frontend typecheck, lint, and build pass.

Context and blast radius

  • frontend/src/components/ReactionBar.tsx owns the summary markup at lines 418–451. Its non-message guard means this exact summary renders for post, comment, and post-image targets only.
  • PostCard.tsx, PostMediaGallery.tsx, and CommentItem.tsx consume ReactionBar; no page should gain its own reaction-summary styling.
  • MessageBubbleRow.tsx has a separate MessageReactionBadge; it is explicitly outside this change.
  • ReactionIcon.tsx already accepts a class name on its glyph span. The adjustment belongs at the summary call site, not in that shared renderer, so picker and message icon sizing cannot regress.

Closest analog: the existing summary stack in ReactionBar.tsx; it already contains the supplied outer wrapper, circular background, and ring.

Constraints

  • Must: preserve the current semantic button, aria label, dialog wiring, icon ordering, total count, and -space-x-1 stacking.
  • Must: keep the spacing scoped to summary icon containers; use existing Tailwind utilities or scoped styles without adding a dependency or a second reaction renderer.
  • Must not: alter message reaction badges, reaction API calls, summary data, picker interaction, global emoji sizing, or theme tokens.
  • Out of scope: changing the total-count typography, reaction emoji set, icon order, hover treatment, or any other feed/chat polish.

Risk — Level 1: localized visual adjustment

The same component serves posts, images, and comments, so an overly broad change could alter all three. Mitigation: limit the modification to the existing non-message summary mapping and verify both one-icon and overlapping multi-icon states in light and dark themes. No database, API, accessibility-contract, or dependency risk is introduced.
